# AI Studio

A polished Next.js AI creative workspace for image generation, video generation, image/video editing, projects and history.

## Stack
- Next.js + React + TypeScript
- Framer Motion
- Lucide React
- Responsive custom CSS

## Current phase
The UI foundation is implemented with a real interactive workspace and provider-ready architecture target. AI provider credentials must be added as Vercel environment variables before production generation endpoints are enabled.

## Run
npm install
npm run dev
